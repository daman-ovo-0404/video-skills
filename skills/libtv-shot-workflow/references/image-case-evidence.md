来源为达蒙指定的五个自有 LibTV 项目，2026-09-28 官方 CLI 导出及当日研究记录。这里只保留支持图片方法的节点与限度。`params.prompt` 表明当前提示，真实输入和图边表明当前关系；已有产物、历史实际提交和当前配置仍需分别核对。

本轮技能整理重新读取了末节七个原文样本的节点 JSON 和五份 `review.md`；其余链条据对应研究记录整理，没有新增图片生成或视觉抽查。以下“已看”均指原研究当日记录的图片检查。本地完整来源目录（相对于九号工作区，未随仓库分发）：`outputs/LibTV五项目蒸馏_20260928/`。

## 1．身份与当前状态分别描述

来源：[小橘游成都](https://www.liblib.tv/canvas?projectId=0e7c3055d792405ba6a5f3412164d200&spaceId=10025099)，`P1/review.md`。

- **观察**：`i-6abg724paanr` 为无包、无持物的角色本体；`i-nh6s4gruc2zx` 指定手机正反面，二者接入持机状态 `i-4qnwujxfm36z`。本体与持机图又接入 `i-um82t63e8er2`；后者提示分别采用本体的身份结构与持机图的背包细节，要求双爪空置。
- **可迁移动作**：换装或持物时先分清什么不变、什么改变；同图可以承担多项明确职责。检查脸型、花纹、背带和持物，不能只看脸。
- **限制／反例**：持机节点把本体参考称作“背包状态图”，与本体禁背包冲突。职责说明必须按实际资产修正。原研究未把所有状态图逐张做视觉一致性审核，不能宣称这套资产已全面验证。

## 2．多视图服务身份与衣装，规格以真实结果核对

来源：[班尼打工日记](https://www.liblib.tv/canvas?spaceId=9720326&projectId=2b0af7bfd17c48f3acae8ebe152bcffc)，`P2/review.md`。

- **观察**：`i-KV0qhkFPj6 → i-Srq87k9pPu → i-6p8LfSlvxK` 依次处理面罩／服装标志、额头膏药、四宫格。原研究看过末图，确有正脸、45°侧脸、颈部以下正面衣装、背面衣装；上部约四成、下部约六成。
- **可迁移动作**：脸与衣装需要不同展示面积时采用多视图；逐格核验角色及服装版本。
- **限制／反例**：原 prompt 写 9:16，settings 为 3:4，产物为 1760×2352。该图当前无出边；相似的被引用副本 `i-ohtaNyVEWM` 当前无入边，不能补齐其制作历史。

## 3．白模可帮助分离结构与材质

来源同上，`P2/review.md`。

- **观察**：`i-31KA8FhsUc → i-K9AV5i1DK2` 去人物；`i-K9AV5i1DK2 → i-E15ZjDFdvc` 转白模；再到 `i-2cC4QJt8cO` 改傍晚老街的材质和逆光。原研究看过白模，记录街道透视、两侧建筑与绿化位置保留，材质大部分去色。`i-E15ZjDFdvc` 原提示为“变成白膜”，原文库应原样保存此字。
- **可迁移动作**：需要重做材质、又重视原场地结构时，可先尝试结构中间版，重点比较消失点和固定物。
- **限制**：只证明本项目采用了该做法；没有成功率对照，不能说白模必然更稳，也不能保证几何绝对不变。

## 4．空间母版写清可见方向关系

来源：[雨声会替我记得你](https://www.liblib.tv/canvas?spaceId=9720216&projectId=50d937e12f4847ffbbec153eb3f285d1)，`P3/review.md`。

- **观察**：`i-y7wLmsg2iA` 与 `i-XfJJhLo0yS` 实际输入无人场景 `i-7GbSOMXuLd`。此图片 prompt 明确背景上方的横向高架电车线路、道路前后关系与电车方向。项目完整空间关系另保存在下游提示中；不能把下游全文冒充本图片 prompt。
- **可迁移动作**：空间图明确固定元素、前后关系、水平／纵深方向，并给出机位。人物与无人场景分开准备。
- **限制**：不同年龄、雨中／干发角色图各有单独节点，但 wet/dry 两图未见同源改图边；单独命名不证明身份一致。原研究的图片抽查覆盖有限。

## 5．去主体时一起处理倒影；用标注明确摆位

来源：[创意 TVC 大猫](https://www.liblib.tv/canvas?projectId=3728fcdbdc21407a96698995482c5e90&spaceId=10025252)，`P4/review.md`。

- **观察 A**：`i-NIwxOjXShu → i-6GkUMyaDvq` 的 prompt 为“去除猫咪和猫咪在地面上的倒影”。原研究看过修改前后图片，记录猫与地面映像消失，阳光、地板和猫窝保留。
- **可迁移动作 A**：空镜清理包括主体产生的倒影和接触阴影，同时保留场景本身的光影。逐一检查残留。
- **观察 B**：`i-HeRqQVeTO5 → i-QuQHhtGUuV` 使用红色轮廓指定城市沙盘中猫的坐姿位置，另输入 `i-fE1bb5eicY` 作为猫参考；后续存在真实裁剪支路。
- **可迁移动作 B**：复杂摆位可用图上标注表达位置和尺度，提示说明标注职责。
- **限制**：标注链只核实输入、提示和产物存在，未专门看图评估落位精度。项目中的猫窝参考不能证明真实产品结构或官方资产身份。

## 6．局部修图同时核对相关事实条件

来源：[咪的河西走廊之梦](https://www.liblib.tv/canvas?projectId=0bcdb06a35ab44e8a47292d961b9370f&spaceId=10025271)，`P5/review.md`。

- **观察**：`3404354e-fae5-4f26-95c4-007c8f30f769` 明确春天、绿皮列车与地面无雪、远处祁连山雪顶；这张图又接入 `d2c4ef74-1772-4ddd-b153-06ed8a070d95` 提取白底橘猫。`a2c8d20d-5518-4d3c-85ca-b60fc5e4c24d` 分支 `82bd511b-8ae4-427a-8dfe-007978e2d032` 去火把，另支 `5bb04627-3ccf-4095-80db-afe3604c62dd` 换麻油灯。
- **可迁移动作**：只改错误对象；季节、地形或光源相互影响时，明确每个对象的状态，再检查关联变化，例如删火把后原火光是否仍存在。
- **限制／反例**：一条提示同时写“唐代画工”与“汉代发髻”，后续才改发髻。原研究未独立核验服饰、器物和地方知识，不能把这些 prompt 当史实资料。上述修图链本次未新增视觉检查，不宣称修改结果均正确。

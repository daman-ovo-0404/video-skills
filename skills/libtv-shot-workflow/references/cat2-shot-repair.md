# 小猫2《慎用远光》：补镜经验与下次使用方法

更新：2026-09-21。适用：已有剧情片的补镜、车辆外观修正、刺激与即时反应、对白节奏。以下是本项目的实测与判断，不代表所有模型均有效。

## 下次遇到相似任务时

1. 先读用户实际剪辑版和待替换镜头，标明原片入出点；不要用生成主片的时间码代替剪辑版时间码。
2. 写一句本镜让观众看懂什么。若灯亮、会车、道路结构和人物反应同时出错，分别定位；可独立替换的困难镜头单开节点，保留原主片。
3. 先检查起始状态与参考一致。正常行驶起跑应有睁眼、闭嘴、无眩光参考；闭眼受晃图可限定后续反应，不能兼作正常行驶首帧。
4. 即时反应用“刺激发生时，一边X一边Y”描述共同发生的动作；再给时间窗口。将“受晃、眯眼、说话”逐项串联，可能造成表演停顿。仅添加时间码不足以解决。
5. 已有自然完整的表演，只差入点时，优先音画同步裁切。涉及中间停顿、对白截断或空间错误时，不能靠裁开头解决。保留原始生成与剪辑版，并报告实际时长。

## 参考图的具体分工

| 输入 | 用途 | 避免混淆 |
|---|---|---|
| 原片或合格候选的起始帧 | 人物、车色、构图、机位、起始姿态 | 不把截图字幕或错误车徽一起继承 |
| 后续状态图 | 后续表情、姿势、灯光变化 | 明说仅是状态参考，除非确实选择首尾帧模式，否则不称为尾帧 |
| 独立logo资产 | 实体车徽的细节 | 单独提供；不让整张白底logo图变成场景或发光图案 |

达蒙明确要求：后续涉及车辆／logo的图片和视频生成，单独加入对应logo参考。本项目沿用参考1画面、参考2独立logo、参考3后续状态图；编号按实际输入解释，不能只在文字中提到而未接入。正式VI成品另按品牌规范使用确认资产；物理车徽生成的候选不等于正式VI验收。

修正产品外观时，优先原片截帧→结合真实车型／独立logo修静帧→检查静帧→用该图补拍。原片抽帧仍需检查手部、结构和方向，不能自动视为合格产品母图。

## 提示词与实片分别验收

- 机位：核对相邻镜头的世界方向、行驶方向、车道与摄影机所在侧；比较主体在画面中的大小。F12虽写“不拉远”，仍生成了更大的景别。
- 灯光：写光源来自哪里、照到什么、角色如何反应；照墙或无叙事作用的光斑不能替代照路。车灯和车徽是否发光分别约束。
- 剧情衔接：尴尬停顿先用已建立的动作、声音或剪辑节奏解决；新插入角色需要动机和位置依据。CTA可独立节点，剧情镜头按叙事需要安排，不让口号干扰前段表演。
- 字幕：本项目生成阶段无字幕，参考图有硬字幕先处理；字幕后加。其他项目遵循当前需求。
- 对白：提示词、音轨存在、嘴部动作、实际说出的词是不同检查项。短句ASR低置信度或复述初始提示时，不当作已听清。画面检查不能确认台词。
- 节奏：常规首中尾帧加关键反应区逐帧检查，记录刺激帧和开口帧。精确秒数以输出fps与帧号计算。

## 已观察的结果与限制

| 轮次 | 修改／观察 | 可复用结论 |
|---|---|---|
| F10静帧 | 原片8秒帧，加入单独logo后第二版获用户认可 | 在这次修图中，独立细节参考有帮助；不能据此承诺后续视频车徽稳定 |
| F12黑猫 | 校正静帧＋logo生成4秒，景别扩大，车徽偏小 | 独立补镜与参考图仍不能保证构图遵循 |
| F13橘猫 | 受晃后嘴部动作约3.2—3.7秒才出现；用户指出间隔长 | 即时反应不能分成受晃后等待再讲话 |
| F14橘猫 | 加正常行驶起始帧，保留受晃状态图和logo，强调同步反应；24fps第45帧（1.875秒）光照与嘴部动作出现，第46帧眯眼 | 该轮视觉反应更连贯，但没有严格执行提示词1.5秒；多项输入同时修改，不能归因于某一措辞单独奏效 |
| F14剪辑版 | 音画同步去掉开头0.375秒，刺激落在1.5秒，实际3.689秒 | 简单入点偏差可后期处理；不把它称为模型精确生成了1.5秒 |

F14对白内容仍待听审，最新片段尚无用户接受或剪入成片的证据。以上沉淀的是方法与可观察变化，不是整片验收结论。

## 操作与归档

- 当前模式schema先核对媒体组合；多张状态参考＋logo需要能接多图的模式，不根据“两张参考”自动选首尾帧。
- 提交前回读真实入边、输入列表及顺序、完整提示词、时长、声音、数量。已有同步生成进程就继续等待同一次任务，避免重复提交。
- 每轮保存原片时间点、参考、实际提交提示词、节点／任务ID、结果文件、审阅说明。用户截图只能定位问题；尽量从原视频抽取干净帧。
- 下载完成再做ffprobe与完整解码，按原始fps查看关键动作。旧版本保留；候选、用户选定、剪入、导出分别记录。

## V01｜引用实际选用片段，动作以完成状态相接

**节点：** P1 `v-9fsw9qs3t4bw → v-p5gydqs24xjz`；另有逛街原片 `v-999pmfbh439e → v-8uYOdqNt3i` 剪辑 → `v-wqkc2dwaknbf` 自拍。

**触发与动作：** 已有前镜，需要继续交易或自拍。续段实际输入前段视频／剪辑资源，另给角色、道具、场景和声音职责。付款段先操作手机、出现反馈、收回手机，随后接碗、展示和品尝。

**观察与检查：** 相邻采样帧的角色左右、摊位、背景和光线接近，付款到品尝的顺序可辨。手机取出与收回有遮挡，不能确认进入背包内部；本轮未核验支付音。检查真实邻接帧与关键接触，不凭“无缝”措辞验收。

**失败调整：** 先查实际引用版本，再处理起始状态与因果。P1 自拍大流程成立，但猫曾坐下，违背“保持站立”；提示的照片与字幕时间也偏移。将姿态与时码独立列为验收项。

## V02｜细表演与声音分别设计

**节点：** P2 `v-8SY6Ovfm4y`；P3 `v-AdDgpGHlYA`、`v-UXpEN1OXBd`；P5 `a744453f-5add-477d-826c-6ce4a110cc27`。

**触发与动作：** 多人对话先固定座位、说话人、身份和声音来源；安静叙事用目光、握持、松手、迟疑表达情绪；旅行感受可用一个刺激对应耳朵、眼睛或鼻子的反应。P5 飞机耳镜头指定猫脸对焦、雪山虚焦。

**观察与检查：** P5 抽帧可见竖耳→平贴、眯眼→恢复，背景虚焦；“胡须全部后倒”未证实。P2 六帧可见关系全景、近景与报价单，不能证明全部台词和离场动作完成。P3 细动作时间有装不下镜头的矛盾。听校台词，检查动作完成与总时长；秒数细不等于执行精确。

**失败调整：** 改概括情绪为可执行身体动作；对白装不下时保留原句，调整镜头时长或拆镜。将“谈话阶段坐着，结束时起身”写清，避免全程坐着与离场相冲突。

## V03｜问题和区间定义局部重拍

**节点：** P1 `v-vf6burv83kvw → v-5wazukoUJv`；P2 `v-QGIlLafUel → v-qskZzrUjWG / v-RnQ6ur9a0V`，另有 `v-3IHO0OL0Ox → v-851Y8wnEif`。

**失败调整：** 检查修改行为、接缝、其他段落及总时长，再决定是否重新覆盖区间。短指令适合明确差异，不构成短提示普遍优于长提示的结论。

## V04｜固定空间，剪出承接部分再续写

**节点：** P3 无人场景 `i-7GbSOMXuLd` 被六条视频引用；续写链 `v-XDlTyi92fD → v-ux76LgkMG0 → v-A95lqkzTmQ → v-alNTQNQooR → v-ET9MnO1wgN → v-iKcZ29euVt → v-UXpEN1OXBd`。

**触发与动作：** 多段故事保留人物身份和场地母版，再以真正选用的剪辑资源续写。场地清单记录道路、护栏、电车、站位与摄影机所在侧。

**观察与检查：** 当前边和输入列表证实这些引用，首末段抽帧保留可辨认的场地。剪辑节点未保存完整入出点，因此不称“每次取原片最后几秒”。静帧不能确认电车全程方向和全部切镜轴线。

**失败调整：** 自然语言“对 续写”留空与真正缺输入分开判断；先查列表及资源。检查世界方向、邻接姿态、声音接缝，清理模板中黑场、文字、时长及运镜矛盾。

## V05｜空镜起幅与产品落幅各有明确职责

**节点：** P4 `i-6GkUMyaDvq → v-28BZzqTDwz`；比较 `v-2bhgR4fF0H`。反转参考为 `v-dXAWDKJ4qy`。

**触发与动作：** 角色需从画外进入，使用去掉角色及倒影的空镜，再单列身份、产品、中途状态和居中落幅。尺度反转先固定城市近景和客厅沙盘全景，再写停顿、拉远揭示、离场。

**观察与检查：** 旧候选首帧猫已在画内；新候选首帧为空，猫从右侧出现并最终在居中猫窝睡下。多个输入及时长同时变化，不能归因于一句提示。反转抽帧出现城市→沙盘→桌面，未证明逐帧结构无变化。

**失败调整：** 先修输入状态；检查起始空镜、入场侧、接触与落幅。若目标是摄影机揭示，逐帧检查后决定是否删除“建筑演变为塑料”等诱导变形的描述。

## V06｜触发时机与精确动画应独立验收

**实际反例：** P5 猫仍在右下时壁画已经发光。P1 角色跑近伸爪可见，但退字顺序和逐笔要求未执行，结尾未遮满屏幕。两者均不能因最终出现目标行为就判整体通过。

**失败调整：** 标记主体完全出画与场景反应开始帧；顺序影响叙事时拆镜或加空镜。精确字形和时码使用独立标题层、遮罩及后期合成。这是对失败的工作建议，不是本项目已完成的后期步骤。
